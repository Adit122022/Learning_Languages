# Learning Languages Repository

This repository is a personal learning workspace covering Go, Java, and React Native. It contains hands-on practice files, notes, and small projects that reflect my progress across different technologies.

## What is included

- [Go_Lang](Go_Lang): Go fundamentals, examples, and a simple students API project.
- [Java](Java): Java basics and advanced practice folders.
- [React_Native](React_Native): Mobile app projects built with React Native and Expo.

## Project overview

| Area | Path | Focus |
| --- | --- | --- |
| Go Programming | [Go_Lang](Go_Lang) | Syntax, data types, loops, conditionals, arrays, slices, and a basic API project |
| Java Practice | [Java](Java) | Core Java basics and advanced topics |
| React Native Apps | [React_Native](React_Native) | Mobile UI development with Expo and TypeScript |

## Key projects

- [Go_Lang/students_API](Go_Lang/students_API): A beginner-friendly Go API project.
- [React_Native/TODO_LIST_APP](React_Native/TODO_LIST_APP): A mobile todo app built with Expo Router and TypeScript.
- [React_Native/Recurrely](React_Native/Recurrely): A subscription tracker app for managing recurring payments.

## Getting started

### Clone the repository

```bash
git clone https://github.com/Adit122022/Learning_Languages.git
cd Learning_Languages
```

### Run the Go API project

```bash
cd Go_Lang/students_API
go run ./cmd/students-api
```

### Run the React Native todo app

```bash
cd React_Native/TODO_LIST_APP
npm install
npx expo start
```
